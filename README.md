# Tqres Archetype Workshop · ورشة أنماط تكريس

A static site, in English and Arabic, for the Tqres marketing team's brand archetype exercise.

- `index.html`: the interactive wheel exercise (brands intro, the 12, the Saudi market, Tqres today, Tqres next, and a guessing game)
- `archetypes/`: one page per archetype, as `.html` and `.md`

No build step. On Vercel: import this repo, framework preset "Other", leave build and output settings empty.

Brand placements are a facilitator's read for discussion, not established fact.
